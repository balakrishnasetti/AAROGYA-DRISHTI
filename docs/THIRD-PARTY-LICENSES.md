# Third-party and licence disclosure

The software uses third-party packages declared in the root, `server`, and `client` `package.json` files and resolved by `package-lock.json`. The manifests and installed package metadata are the canonical dependency/license inventory. This project has not yet generated or independently reviewed a complete software bill of materials (SBOM); run an approved license scanner and retain its output before distribution.

The current interface uses a simple text/letter mark. No synthetic doctor avatar, real-person likeness, or licensed face asset is bundled. If an avatar is added, document the asset URL/source, creator, license, model/tool terms, consent or release, and attribution requirements here. Do not use a real person's likeness without written permission.

Provider integrations (Gemini, S3-compatible storage, SMS, email, maps, and video) are optional and have separate provider terms, privacy obligations, and possible usage charges. Their presence in the code is not an endorsement or evidence that an account is configured. Complete provider-specific legal, privacy, security, and retention review before enabling them with personal data.

Review current notices and licenses when upgrading dependencies or adding assets. This disclosure does not replace the licenses included with the relevant packages.
